This document describes the changes made to the software between the _previous_ and _current_ versions (see above). If you don't find something listed here, then it was not done in this timeframe, or it was not considered important enough to be mentioned. The following information is located here: 

  * Changes in the software configuration
  * Changes in libtiff
  * Changes in the tools
  * Changes in the contributed software 


* * *

**C HANGES IN THE SOFTWARE CONFIGURATION:**

  * support was added for building the library as a DSO under OSF/1 


* * *

**C HANGES IN LIBTIFF:**

  * fixes to the Pixar codec 
  * portability mods for VMS 


* * *

**C HANGES IN THE TOOLS:**

  * fixes to **gif2tiff** and **ppm2tiff** for building under MS/DOS 
  * portability mods to **fax2ps** and **ycbcr** for VMS 


* * *

**C HANGES IN THE CONTRIBUTED SOFTWARE:**

  * a new package from Alexander Lehmann for building the library and tools under MS/DOS with DJGPP v2 
  * updated VMS support from Karsten Spang
